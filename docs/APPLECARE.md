# AppleCare+ 购买选项

工作台“购买商品”增加默认关闭的“购买 AppleCare+（AC+）”，用于本次普通下单和定时预购；切换账号或商品后重置。选项变化会撤销定时预购授权，需要重新确认。此选项不写入购买预设，也不改变“结算购物袋”的原有行为。

数据流：界面 `applecare: boolean` → 现有任务参数 → Worker → 按目标 SKU 更新购物袋 → 根据官网当前模型选择 AppleCare → 复核页再次检查 → 原订单确认/提交。定时计划持久化该值，旧计划缺省为不购买。Rust 通道继续透传参数，无需迁移。

仅使用官网页面返回的 action、套餐编号和令牌，不硬编码 AC+ SKU。已有 AC+ 不重复加购；取消勾选时通过官网更改入口取消目标商品的 AC+。不支持、多个可选套餐、状态或接口无法识别时停止；不得忽略用户选择继续下单。请求失败后保留购物袋，通过原有查询/恢复流程核对。订单总额及定时上限均包含 AC+；付款仍由用户完成。

验证：构建与界面夹具验证默认值、勾选参数、账号隔离、定时授权失效；离线 Worker 验证选择/取消/幂等、缺失或歧义套餐、复核不一致及旧计划兼容；不执行真实加购或下单。接口依据为本轮只读获取的官网 `/shop/bag` 所引用 `rs-checkout-5.18.11-16f6e/dist/bag.js`：`inlineRecommendations.*.add`、`changeAppleCareModal`、`changeAppleCare.updateAppleCareSelection` 和 `appleCarePartNumber`。合成模型测试不能代替登录后真实购物袋和订单验证。
